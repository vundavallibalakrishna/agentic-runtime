## How to test visually

1. Start the existing real dependencies and API with the repository local development commands. Set `AR_API_URL` to the running API address and run `AR_WEB_HOST_PORT=3102 AR_NEXT_DIST=.next-ui-preview pnpm --filter @ar/web dev` after confirming that port is free. Authenticated writes require that exact preview origin in the existing API origin allowlist.
2. Sign in with the local tenant admin account. Open Chat: attachment and send controls stay visible; Chat options expands research, agent and model controls.
3. Open Settings: search a destination by its name or explanatory text.
4. Open Models: existing providers and their nested models appear before Model defaults. Expand Add a provider to see the connection form. Open an existing provider's Edit action and cancel without saving.
5. Review Model defaults: assignment changes are described as immediate; incompatible assigned models remain visible with a warning. Simple mode conceals technical alias identifiers; Advanced exposes them.

Focused component tests are regression evidence, not a substitute for the remaining real-service flows.
