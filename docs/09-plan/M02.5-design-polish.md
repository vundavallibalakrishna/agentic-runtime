# M2.5 — Design polish

Presentation only. No new product capability, and the shortcuts in the handover (in-memory chat, requests that do not go through the model gateway, runs without a Temporal worker, memory-store writes without an audit row) stay as they are.

**Depends on:** M2 exit.

**Spec:** [design-system](../08-quality/design-system.md), [ux-quality](../08-quality/ux-quality.md), [spec 19](../03-specs/19-web-app.md), [local-dev](../07-ops/local-dev.md), [spec 01](../03-specs/01-api-bff.md).

## M2.5-T01 — Design system, shell and screens

**Do:** Tokens, light and dark, the app shell, branded sign-in for the four seeded users, polished chat, and the existing models, users, agents and platform-health pages on that shell.

**Done when:** Feature code uses tokens. The theme defaults to the system preference. Chat streams without pulling the scroll position. Models has Simple and Advanced.

**Tests:** Web unit tests, the existing Playwright chat path, axe on the home page.

## M2.5-T02 — Local run and Keycloak

**Do:** A fresh clone on a machine where 5432, 6379, 7233, 8000, 8001 and 8013 are taken still comes up with `make dev AUTO_PORTS=1`. Keycloak sign-in over plain HTTP creates a session for each seeded user. The callback resolves the `dev` organisation (including the Keycloak object-shaped claim and an `@dev.local` address with no claim).

**Done when:** The bugs listed in the milestone handover are fixed in the repo, not by a local workaround.

**Tests:** `services/api/tests/unit/test_oidc_login.py`, `libs/ar_common/tests/unit/test_host_ports.py`.

## M2.5-T03 — Fresh-clone CI

**Do:** A CI job runs bootstrap, moves busy default ports, starts dependencies, migrates, seeds, checks that a second port pass does not move ports this project already published, starts the app processes, and smokes health, the four dev logins, and the Keycloak username-then-password form.

**Done when:** `.github/workflows/ci.yml` job `fresh-clone` is green.

**Tests:** `scripts/fresh_clone_smoke.py` in that job, and `services/api/tests/unit/test_fresh_clone_smoke.py` for the form parser.

## M2.5-T04 — Visual test

**Do:** Checklist, before/after screenshots in light and dark at desktop and mobile widths, and a walkthrough recording.

**Done when:** `docs/testing/m2.5-checklist.md` exists and the images and recording are in `docs/testing/m2.5/`.

## Exit

A reviewer can sign in as any seeded user, switch theme, open the command palette, and read a streamed answer in a centred column. `make bootstrap && make dev AUTO_PORTS=1` is the local start. The click-through is the checklist.
