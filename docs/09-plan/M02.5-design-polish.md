## M2.5-T01a — Workspace presentation refinement

**Depends on:** M2.5-T04, M3-T08. User-requested maintenance of completed screens after M12; no later milestone capability is introduced.

**Spec:** [design-system](../08-quality/design-system.md), [ux-quality](../08-quality/ux-quality.md), [spec 19](../03-specs/19-web-app.md).

**Do:** Refine the neutral palette, grouped navigation, chat welcome and composer, and agent catalogue. Review existing management and detail pages for positioning: consistent page headers, list/form columns, field widths, action placement, settings selectors and empty states. Finish loading, failure/retry, pending, completed and read-only detail states. Review implemented M2–M12 journeys end to end, including SSO, draft publication, approvals, knowledge, memory, skills, routines, channels and quotas. Repair issues discovered in these journeys and add targeted regression checks. Preserve existing permission checks. Start the local stack while retaining the existing database volume.

**Done when:** Light and dark layouts work at 375 and 1280 pixels; navigation and chat remain usable with a keyboard; catalogue and detail loading, empty and error states provide clear next actions; existing management pages keep lists ahead of creation forms and do not overflow at either width. Draft-save failures cannot publish older content, completed decisions have no live decision form, and late chat responses cannot replace a newly opened conversation.

**Tests:** Web unit suite, TypeScript and Biome checks, Playwright M2–M12 journeys, `chat-recovery`, `screen-layouts` covering 16 management pages and approval states, and `detail-screens` covering seven details plus builder/source/profile, axe checks, and light/dark screenshots. Run repository checks and record exact outcomes and startup commands in `docs/testing/workspace-polish.md`, `docs/testing/screen-layout-review.md` and `docs/testing/detail-flow-review.md`.

A reviewer can sign in as any seeded user, switch theme, open the command palette, and read a streamed answer in a centred column. `make bootstrap && make dev AUTO_PORTS=1` is the local start. The click-through is the checklist.
