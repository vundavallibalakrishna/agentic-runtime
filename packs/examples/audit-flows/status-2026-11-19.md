# Status against the audit requirements, 19 November 2026

This is where the platform stands on each requirement code, from running 18 chat scenarios
against a real model. The answers and tool calls of the last run are in
[evidence.json](evidence.json). The scenarios and sample data are in [scripts](scripts) and
[fixtures](fixtures); the sample data is invented and its right answers are known
([answers.json](fixtures/answers.json)).

Everything below is a generic platform capability. Nothing is specific to one industry.

## How to read this

- **Works**: correct in every run of the last four.
- **Partly**: the capability is there and gives a correct result in some runs, but not all,
  or one part of the requirement is not met.
- **Not yet**: not built, or not tested.

One caveat applies to every row. The runs used a small open-weight model (Qwen3-32B). The
platform's own parts behaved the same in every run: sampling, queries, sign-off, file
creation. What varied was the model: which tool it picked and how well it wrote a query. The
same scenarios should be run again on the model the customer will use before any figure
here is quoted to them.

## AI assistance

| AAT103 | Executive summary of an engagement's observations | Works | Grounded in the notes, with references. |

| AAT103 | Label output as AI-generated until a person accepts it | Works | Every reply shows "AI-generated · not reviewed". |
| AAT103 | Cite the source of each statement | Works | Document answers carry passage references. |
| AAT103 | Named approval with user and time before output moves on | Works | A person accepts a reply; the name, time and exact text are recorded and returned by the API, so a calling system can block anything not accepted. Off until a review queue is chosen. |

| AAT104 | Run the proposed rule on sample data and show output and count | Partly | Saving a rule with a sample file runs it once and shows the rows and the true count. | AAT104 | No rule runs without a named person's approval | Works | A saved rule is blocked until someone other than its author signs it. The approver sees the name, version, description and statement. |
| AAT104 | Versioned rule library with approver and date | Works | Each save is a new version that cannot be edited. A run reports who approved it and when. |
| AAT104 | A changed rule goes through approval again | Works | A change is a new version with its own sign-off. |
| AAT105 | Build a risk and control matrix from source documents | Partly | Produced a matrix with risks, controls, control type and owner in some runs. In others it picked the wrong tool and produced no file. |
| AAT105 | Reference each line to the source paragraph | Partly | Lines carry a passage reference, not the document's own paragraph number. |
| AAT105 | Flag a risk that has no control, without inventing one | Partly | Flagged correctly in one run, left out in another. |

## Data sampling and analysis

| Code | Requirement | Status | What happens today |
|---|---|---|---|
| AAT059 | Random, monetary unit, stratified and full-population sampling, reproducible and documented | Works | The same file and seed give the same rows. The result states the method, seed, population, interval and counts, and attaches the sample as a file. |
| AAT059 | Judgmental sampling | Works | See AAT061. |
| AAT060 | Filter by amount, frequency, user and flags, alone and combined | Works | Counts matched the known answers in every run. |
| AAT061 | Judgmental additions with a mandatory reason, clearly flagged | Works | Added rows are marked judgmental with the reason. A missing reason is refused. One of four runs had a failed call. |
| AAT062 | Free-form queries without preset filters | Works | For files a person attaches. Queries against a live database or logs need a connector and were not tested. |
| AAT062 | Respect the user's permission scope | Not yet | Not tested in these runs. |
| AAT063 | Results as a table, a chart or a dashboard | Partly | Tables, pivots, charts and Excel export work. There is no dashboard. |
| AAT064 | Save, version, share and reuse queries on current data | Works | A saved query is run again on a new file, never from a stored result. |

## Known limits

- Tables of more than 5,000 rows are refused by the table tools.
- A document of more than 40,000 characters is refused by the inconsistency check.
- An agent stops after 8 model steps, 8 tool calls or 120 seconds by default. These are
  settings on the agent.
- A chat turn took 10 to 120 seconds.
